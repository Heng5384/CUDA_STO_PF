# Agent instructions

Before changing code, preparing a run, interpreting a report, or proposing a
new scientific path in this repository, read:

- `PROJECT_CORE_MEMORY.md`

Treat that file as the authoritative project scope, scientific boundary,
current roadmap, and latest status. Preserve historical evidence, but do not
allow an older report to override the current core memory.

In particular:

- the current main study is post-nucleation resolved-beta evolution from 6 h
  to 48 h;
- GP-assisted nucleation, GP Birth, GP release, and absolute first-beta
  nucleation timing are outside the current main study;
- case-specific physical retuning is forbidden;
- PF does not predict dislocation density;
- particle identity results must fail closed on unresolved merge/split events;
- every production result must preserve source, parameter, binary, fixture,
  and analysis provenance.
