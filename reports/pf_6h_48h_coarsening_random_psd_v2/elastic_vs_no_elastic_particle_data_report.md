# 有弹性 / 无弹性颗粒演化数据汇总审计

## 1. 报告范围

本报告整理当前本地可追溯的两类结果：

1. **无弹性 72831**：246³、96 个随机 PSD 有效颗粒、T380、6–48 h
   完整 VTK 轨迹；
2. **有弹性短时结果**：96³ 三颗粒 A/B/C 对照，以及 equilibrium audit
   中的固定胞周期弹性 R=8/10/12/14/20 nm 短窗口。

目前本地没有与无弹性72831完全同一246³随机PSD初态、同一6–48 h时间窗
对应的有弹性完整运行。因此，弹性部分不能被表述为“246³有弹性48 h
结果”；它是已完成的短时弹性效应和守恒/重启证据。

## 3. 无弹性 6–48 h 颗粒轨迹

### 3.1 轨迹审计

- 快照数：43（6–48 h）；
- 轨迹行数：980；
- 初始有效颗粒数：96；
- 48 h有效颗粒数：8；
- merge/split：未检测到；
- 未跟踪组件：0；
- 身份规则：最大体素重叠，周期质心距离作为并列决胜；
- 颗粒体积：`sum h(phi)`；
- 等效半径：`R=(3 V_h / 4π)^(1/3)`。

### 5.4 弹性边界与方向

弹性路径是固定胞、周期边界、`E0=0` 的谱 Green-function 求解；k=0
位移模被置零。这不是 traction-free 或 zero-macroscopic-stress
变量胞模型。已测试的是 principal eigenstrain 的 x 方向：

```text
[0.046, -0.022, -0.017]
```

y/z 方向排列没有完成对应变体测试，不能宣称各向取向已经完整资格化。

## 7. 综合判断

1. 无弹性72831已经给出完整6–48 h随机PSD粗化轨迹：96→8，矩阵xB
   总体下降，存活颗粒长大，且未观察到merge/split。
2. 有弹性本地证据目前是短时固定胞结果。它显示弹性对短时粒子体积的
   影响较小（约0.1–0.2%半径变化），但对局部xB场的影响比体积变化更
   明显，并带来约2.09倍步时开销。
3. 目前不能从这些文件得出“弹性使6–48 h颗粒轨迹如何改变”的定量结论，
   因为缺少匹配初态、匹配网格、匹配时间窗的有弹性246³续跑。
4. 弹性 equilibrium audit 的最终科学状态仍为
   `INCONCLUSIVE_MORE_EVIDENCE_REQUIRED`，方法阻塞为
   `BLOCKED_PROFILE_EQUILIBRATION_METHOD`。
