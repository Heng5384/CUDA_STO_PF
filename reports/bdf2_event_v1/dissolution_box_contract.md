# Dissolution box contract

The previously rejected 512/1024 nm dissolution setup is not a valid 8 nm
mass-reachability test.  This goal preserves the frozen minimum box sizes:

- minimum validated dissolution box: `3072 nm`
- preferred dissolution box: `4096 nm`

No dissolution campaign is run in this goal.  The present scope is limited to
the T400 planar active-set crossing and, only after that gate passes, the
growth-side 8 nm numerical qualification.
