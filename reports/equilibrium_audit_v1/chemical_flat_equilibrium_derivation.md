# Chemical flat equilibrium derivation

For a pure Ag2Te endpoint, the common tangent condition reduces exactly to `mu_B(x_alpha,T)=G_Ag2Te^0(T)`, which is also the runtime `solve_x_eq_device` equation. At 380 °C:

- `xB_eq = 0.00466495182145419`
- `xAg_eq = 0.0046540962540554`
- `L(T) = 29423.5425 J/mol`
- `RT = 5430.59125905 J/mol`

The independent common-tangent residual is below machine precision in `chemical_flat_equilibrium_root.csv`.
