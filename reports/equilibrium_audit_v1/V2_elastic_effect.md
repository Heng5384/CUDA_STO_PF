# V2 elastic effect

The clean branch still cannot materialize V2-B under the frozen profile and
zero-mode contracts.  In the isolated extension, the matched B→C comparison
changed equivalent radii by -0.090%, -0.195% and -0.194% for the small,
medium and large particles; the normalized mean phase-field difference was
0.31%, while local xB excursions were larger.  This is a bounded fixed-cell
elastic-effect diagnostic, not a clean production claim; see
`multi_particle_v2_results_v1.md`.
