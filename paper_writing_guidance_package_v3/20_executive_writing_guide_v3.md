# Executive writing guide V3

## One-sentence story

Ag-alloyed PbTe contains a finite-lifetime, interface-rich low-κ state whose coarsening path is selected by PSD and spatial organization, while loss of interfacial area sets the leading modeled thermal recovery.

## Primary punchline

“Ag-alloyed PbTe exhibits a metastable low-thermal-conductivity window sustained by an interface-rich precipitate population. PSD and spatial organization determine how this population coarsens, whereas the loss of interfacial area determines how the thermal window closes.”

## Writing order

1. State Sheskin's low-κ state and κ recovery.
2. Explain why observation windows require admissible ensembles.
3. Define the conserved-elastic post-nucleation propagation.
4. Present fixed-PSD Case 001–003 as spatial uncertainty/robustness.
5. Contrast survival/`M6` sensitivity with V2 Δκ robustness.
6. Explain `Sv` as the leading modeled closure variable and `M6` as tail information.
7. Use Yu only for broader defect redistribution.
8. End with window lifetime as the design target and temperature/elastic bias as tests.

## Tone

Prefer `reveal`, `identify`, `separate`, `select`, `sustain`, `close`, `bound`. Use `determine` and `govern` only with explicit scope. Reserve `prove`, `validate`, `predict`, `reconstruct`, `control` and `quantitatively reproduce` for evidence that currently does not exist.

## Non-negotiable qualifiers

- Case 001–003: complete-checkpoint conditional analysis pending production authority.
- `Sv` outcome: within the frozen V2 interface-scattering contract.
- low-κ, not high-zT, window.
- full PSD remains authority; `Sv+M6` is a compression.
- Sheskin and Yu are complementary but non-interchangeable.
- temperature and elastic bias are testable routes, not demonstrated controls.

## Ending rule

Do not finish with “the model cannot explain the experiment.” Finish with: “The processing target is not a unique precipitate arrangement, but the lifetime of the interface-rich low-κ state.” Place the bounded residual immediately before the forward tests it motivates.
